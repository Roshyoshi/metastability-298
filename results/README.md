# Retained measurement results

Keep accepted characterization results and silicon measurements here. Each
run needs its circuit/source revision, tool and PDK versions, invocation,
process corner, voltage, temperature, loading, and raw measurements alongside
derived summaries.

Preserve failed criteria and diagnostic reruns separately so a later fit does
not replace the evidence behind an earlier conclusion. For silicon runs,
include die identity and calibration records.

Use `build/` for disposable logs, generated netlists, and exploratory output.
